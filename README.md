# 🌐 Personal Portfolio

A modern and responsive personal portfolio built to showcase my skills, experience, and professional background as a **Web Developer**. This website serves as my online resume, making it easy for recruiters and collaborators to learn more about me, explore my work, and get in touch.

🔗 **Live Demo:** https://portfolio-web-five-drab.vercel.app

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- Formspree
- Git & GitHub
- Vercel

---

## 💡 Why I Built This

I wanted to create a portfolio that represents who I am as a developer today while providing a professional space where recruiters and potential collaborators can easily learn about my experience, access my resume, and contact me.

This project also allowed me to improve my front-end skills by focusing on responsive layouts, user experience, semantic HTML, CSS animations, and clean design principles.
